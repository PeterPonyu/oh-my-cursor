Great prompt. I’d run the interview against these **four clarity dimensions**:

- **Business Decision Clarity** — how clearly we know which decisions analytics must enable  
- **Outcome Metric Clarity** — how clearly success/failure is defined (activation, retention, revenue, etc.)  
- **User/Journey Clarity** — how clearly personas, lifecycle stages, and key flows are mapped  
- **Instrumentation/Constraint Clarity** — how clearly event definitions, data quality needs, and constraints (privacy, team, timeline) are known

- **Outcome Metric Clarity:** 2/10

- **Instrumentation/Constraint Clarity:** 1/10
